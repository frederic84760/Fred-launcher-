# Installation sur Honor Magic7 Pro

1. Ouvrir le projet dans Android Studio et compiler `app`.
2. Installer l’APK debug sur le téléphone.
3. Lancer **Fred Launcher** une première fois.
4. Faire un appui long sur le fond > **Définir Fred par défaut**.
5. Dans les réglages Android / MagicOS, choisir **Fred Launcher** comme application d’accueil.
6. Revenir à l’écran d’accueil.

Pour revenir au launcher Honor, rouvrir les réglages de l’application d’accueil et sélectionner **Accueil Honor**.
